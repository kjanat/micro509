micro509/jose ​

Optional JOSE surface: signed compact JWS and JWT (RS256), JWK Sets, and opt-in remote JWKS resolution. Importing this entrypoint performs no network access.

Start with verifyJwt for tokens, createJwksKeyResolver for a local JWK Set, and createRemoteJwksKeyResolver to read keys from a trusted URL.

Functions ​

  • createJwksKeyResolver — Creates a key resolver over a fixed JWK Set.
  • importJwkEntry — Imports a selected entry as a verify-only RS256 CryptoKey.
  • parseJwks — Parses a JWK Set document.
  • selectJwk — Selects the one key of a set that can verify selector.
  • parseCompactJws — Parses a compact JWS without checking its signature.
  • signCompactJws — Signs a compact JWS with an existing private CryptoKey.
  • verifyCompactJws — Verifies a compact JWS.
  • decodeJwtUnverified — Decodes a JWT without checking its signature. Every field of the result is unauthenticated.
  • signJwt — Signs a JWT. The header carries typ: "JWT" unless header.typ says otherwise.
  • verifyJwt — Verifies a JWT: the signature and tokenType policy as verifyCompactJws applies
  • createRemoteJwksKeyResolver — Creates a key resolver that reads a JWK Set from one trusted URL.
