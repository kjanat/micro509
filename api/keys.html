micro509/keys ​

Generate keys and move them between WebCrypto, PEM, DER, and JWK formats.

Start with generateKeyPair. Load a private key with importPkcs8Pem, or protect an exported key with exportEncryptedPkcs8Pem.

  • decryptRsaOaep — Decrypt an RSA-OAEP ciphertext with the matching private key.
  • decryptRsaOaepOrThrow — Decrypt an RSA-OAEP ciphertext with the matching private key.
  • derivePublicKey — Derive the matching public key from an imported (or generated) private key.
  • encryptRsaOaep — Encrypt a small message with an RSA-OAEP public key.

Types ​

  • DecryptRsaOaepErrorCode — Machine-readable failure reason for decryptRsaOaep.
  • DecryptRsaOaepFailure — Structured failure payload for decryptRsaOaep.
  • DecryptRsaOaepResult — Success-or-failure result returned by decryptRsaOaep.
  • EcKeyAlgorithmInput — ECDSA variant of KeyAlgorithmInput.
  • EcNamedCurve — NIST elliptic curve for ECDSA keys.
  • Ed25519KeyAlgorithmInput — Ed25519 variant of KeyAlgorithmInput.
  • EncryptedPkcs8Options — PBES2 encryption options for the encrypted PKCS#8 export/import functions.
  • EncryptRsaOaepErrorCode — Machine-readable failure reason for encryptRsaOaep.
  • EncryptRsaOaepFailure — Structured failure payload for encryptRsaOaep.
  • EncryptRsaOaepResult — Success-or-failure result returned by encryptRsaOaep.
  • ImportEcKeyInput — ECDSA variant of PublicKeyImportInput / PrivateKeyImportInput.
  • ImportEd25519KeyInput — Ed25519 variant of PublicKeyImportInput / PrivateKeyImportInput.
  • ImportEncryptedKeyErrorCode — Machine-readable failure reason for the importEncrypted* key functions.
  • ImportEncryptedKeyFailure — Structured failure payload for encrypted key import.
  • ImportEncryptedKeyOptions — Options for the encrypted PKCS#8 import functions.
  • ImportEncryptedKeyResult — Success-or-failure result returned by the public importEncrypted* key functions.
  • ImportKeyErrorCode — Machine-readable failure reason for the import* key functions.
  • ImportKeyFailure — Structured failure payload for key import.
  • ImportKeyResult — Success-or-failure result returned by the public import* key functions.
  • ImportRsaKeyInput — RSA variant of PublicKeyImportInput / PrivateKeyImportInput.
  • KdfLimitOptions — Caller-supplied bound on password-based KDF work.
  • KeyAlgorithmInput — Input for generateKeyPair. Selects algorithm family and parameters.
  • KeyPairMaterial — Key pair with convenience export helpers. Returned by generateKeyPair.
  • LegacyPemEncryptionOptions — Options for OpenSSL-style Proc-Type: 4,ENCRYPTED PEM encryption (PKCS#1/SEC1).
  • Pbes2EncryptionOptions — Input for encryptPbes2.
  • Pbes2EncryptionScheme — AES-CBC key sizes supported by this PBES2 implementation.
  • Pbes2Parameters — Resolved PBES2 algorithm parameters, either parsed from DER or built by encryptPbes2.
  • Pbes2Prf — PBKDF2 pseudo-random function choices. HMAC-SHA-1 is the RFC default; HMAC-SHA-256 is preferred.
  • PrivateKeyImportInput — Algorithm descriptor for private key import functions. Same shape as PublicKeyImportInput.
  • PublicKeyImportInput — Algorithm descriptor for public key import functions.
  • RsaHash — Hash algorithm paired with an RSA key.
  • RsaKeyAlgorithmInput — RSA variant of KeyAlgorithmInput.
  • RsaOaepOptions — Options shared by encryptRsaOaep and decryptRsaOaep.
  • RsaScheme — RSA padding scheme: a signature scheme, or 'oaep' for RSA-OAEP encryption
  • RsaSignatureScheme — RSA signature padding scheme.
