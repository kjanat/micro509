micro509/x509 ​

Create and inspect certificates, CSRs, names, and extensions.

Read existing material with parseCertificatePem. Issue a certificate with createCertificate, or generate a key and certificate together with createSelfSignedCertificate.

DER/PEM parsing, encoding, extension decoding, and text rendering return synchronously. Certificate/CSR creation and WebCrypto-backed hashing and key operations return promises and must be awaited.
