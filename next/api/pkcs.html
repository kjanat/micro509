micro509/pkcs ​

PKCS container APIs: PFX/PKCS#12 and PKCS#7/CMS.

Package keys and certificates with createPfx, then read them with parsePfxDer. Use createPkcs7SignedData and verifyPkcs7SignedData for signed content.

  • createPfx — Builds a PKCS#12/PFX archive containing certificates and/or private keys.
  • parsePfxDer — Decodes a BER- or DER-encoded PKCS#12/PFX container into its constituent bags.
  • parsePfxPem — Decodes a PEM-armored PKCS#12/PFX container. Expects exactly one PKCS12 block.

  • createPkcs7SignedData — Creates a PKCS#7/CMS SignedData with one or more signers over content.

  • parsePkcs7SignedDataDer — Decodes a DER-encoded PKCS#7 ContentInfo expecting signedData content type.
  • parsePkcs7SignedDataPem — Decodes a PEM-armored PKCS#7/CMS SignedData. Expects exactly one PKCS7 or CMS PEM block.
  • verifyPkcs7SignedData — Verifies all signer signatures in a PKCS#7 SignedData structure.
