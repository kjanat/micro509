micro509/keys ​

Canonical key generation and import/export domain surface. Owns the stable micro509/keys entrypoint.

Functions ​

  • exportBinaryBase64 — Export a key as raw base64 (no PEM headers).
  • exportEncryptedPkcs1Pem — Export an RSA private key as legacy Proc-Type: 4,ENCRYPTED PEM (PKCS#1).
  • exportEncryptedPkcs8Der — Export a private key as DER-encoded PBES2-encrypted PKCS#8 EncryptedPrivateKeyInfo.
  • exportEncryptedPkcs8Pem — Export a private key as PEM-encoded PBES2-encrypted PKCS#8 EncryptedPrivateKeyInfo.
  • exportEncryptedSec1Pem — Export an EC private key as legacy Proc-Type: 4,ENCRYPTED PEM (SEC 1).
  • exportPkcs1Der — Export an RSA private key as DER-encoded PKCS#1 RSAPrivateKey.
  • exportPkcs1Pem — Export an RSA private key as PEM-encoded PKCS#1 RSAPrivateKey.
  • exportPkcs8Der — Export a private key as DER-encoded PKCS#8 PrivateKeyInfo.
  • exportPkcs8Pem — Export a private key as PEM-encoded PKCS#8 PrivateKeyInfo.
  • exportPrivateJwk — Export a private key as a JSON Web Key.
  • exportPublicJwk — Export a public key as a JSON Web Key.
  • exportSec1Der — Export an EC private key as DER-encoded SEC 1 ECPrivateKey.
  • exportSec1Pem — Export an EC private key as PEM-encoded SEC 1 ECPrivateKey.
  • exportSpkiDer — Export a public key as DER-encoded SubjectPublicKeyInfo.
  • exportSpkiPem — Export a public key as PEM-encoded SubjectPublicKeyInfo.
  • generateKeyPair — Generate an asymmetric key pair for signing and verification.
  • importEncryptedPkcs1Pem — Import an RSA private key from legacy Proc-Type: 4,ENCRYPTED PEM (PKCS#1).
  • importEncryptedPkcs8Der — Import a private key from DER-encoded PBES2-encrypted PKCS#8 EncryptedPrivateKeyInfo.
  • importEncryptedPkcs8Pem — Import a private key from PEM-encoded PBES2-encrypted PKCS#8 EncryptedPrivateKeyInfo.
  • importEncryptedSec1Pem — Import an EC private key from legacy Proc-Type: 4,ENCRYPTED PEM (SEC 1).
  • importPkcs1Der — Import an RSA private key from DER-encoded PKCS#1 RSAPrivateKey.
  • importPkcs1Pem — Import an RSA private key from PEM-encoded PKCS#1 RSAPrivateKey.
  • importPkcs8Base64 — Import a private key from base64-encoded PKCS#8 PrivateKeyInfo (no PEM headers).
  • importPkcs8Der — Import a private key from DER-encoded PKCS#8 PrivateKeyInfo.
  • importPkcs8Pem — Import a private key from PEM-encoded PKCS#8 PrivateKeyInfo.
  • importPrivateJwk — Import a private signing key from a JSON Web Key.
  • importPublicJwk — Import a public verification key from a JSON Web Key.
  • importSec1Der — Import an EC private key from DER-encoded SEC 1 ECPrivateKey.
  • importSec1Pem — Import an EC private key from PEM-encoded SEC 1 ECPrivateKey.
  • importSpkiBase64 — Import a public key from base64-encoded SubjectPublicKeyInfo (no PEM headers).
  • importSpkiDer — Import a public key from DER-encoded SubjectPublicKeyInfo.
  • importSpkiPem — Import a public key from PEM-encoded SubjectPublicKeyInfo.

Types ​

  • EcKeyAlgorithmInput — ECDSA variant of KeyAlgorithmInput.
  • EcNamedCurve — NIST elliptic curve for ECDSA keys.
  • Ed25519KeyAlgorithmInput — Ed25519 variant of KeyAlgorithmInput.
  • EncryptedPkcs8Options — PBES2 encryption options for exportEncryptedPkcs8Der and exportEncryptedPkcs8Pem.
  • ImportEcPublicKeyInput — ECDSA variant of PublicKeyImportInput.
  • ImportEd25519PublicKeyInput — Ed25519 variant of PublicKeyImportInput.
  • ImportRsaPublicKeyInput — RSA variant of PublicKeyImportInput.
  • KeyAlgorithmInput — Input for generateKeyPair. Selects algorithm family and parameters.
  • KeyPairMaterial — Key pair with convenience export helpers. Returned by generateKeyPair.
  • LegacyPemEncryptionOptions — Options for OpenSSL-style Proc-Type: 4,ENCRYPTED PEM encryption (PKCS#1/SEC1).
  • Pbes2EncryptionOptions — Input for encryptPbes2.
  • Pbes2EncryptionScheme — AES-CBC key sizes supported by this PBES2 implementation.
  • Pbes2Prf — PBKDF2 pseudo-random function choices. hmac-sha1 is the RFC default; hmac-sha256 is preferred.
  • PrivateKeyImportInput — Algorithm descriptor for private key import functions. Same shape as PublicKeyImportInput.
  • PublicKeyImportInput — Algorithm descriptor for public key import functions.
  • RsaHash — Hash algorithm paired with an RSA key.
  • RsaKeyAlgorithmInput — RSA variant of KeyAlgorithmInput.
  • RsaScheme — RSA signature padding scheme.
