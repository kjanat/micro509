Not supported ​

micro509 does not try to mirror every primitive some WebCrypto runtimes expose:

  • DSA
  • Ed448
  • RSA-OAEP
  • ECDH / X25519 / X448
  • Generic symmetric-crypto APIs
  • Brainpool curves
