micro509/x509 ​

Canonical advanced X.509 domain surface. Owns certificate, CSR, extension, name, and parse APIs behind one stable entrypoint.

Functions ​

  • createCertificate — Create an X.509 certificate signed by input.signerPrivateKey.
  • createSelfSignedCertificate — Create a self-signed certificate.
  • createCertificateSigningRequest — Creates a PKCS#10 Certificate Signing Request signed with the given private key.
  • buildCertificateExtensions — Build the v3 extensions block for a certificate.
  • buildRequestedExtensions — Build the extensions for a CSR's extensionRequest attribute.
  • encodeAuthorityInfoAccess — DER-encode an Authority Information Access SEQUENCE.
  • encodeBasicConstraints — DER-encode a BasicConstraints value.
  • encodeCertificatePolicies — DER-encode a Certificate Policies extension value.
  • encodeCrlDistributionPoints — DER-encode a CRL Distribution Points SEQUENCE.
  • encodeExtendedKeyUsage — DER-encode an Extended Key Usage SEQUENCE OF OIDs.
  • encodeExtension — Encode a single X.509 Extension SEQUENCE (OID + optional critical BOOLEAN + OCTET STRING).
  • encodeInhibitAnyPolicy — DER-encode an Inhibit anyPolicy extension value (single INTEGER).
  • encodeKeyUsage — DER-encode a Key Usage BIT STRING from an array of KeyUsage flags.
  • encodeNameConstraints — DER-encode a Name Constraints extension value.
  • encodePolicyConstraints — DER-encode a Policy Constraints extension value.
  • encodePolicyMappings — DER-encode a Policy Mappings extension value.
  • encodeSubjectAltName — DER-encode a single SubjectAltName GeneralName element.
  • getAuthorityInfoAccessMethodOid — Resolve an AuthorityInfoAccessMethod to its dotted-decimal OID.
  • getExtendedKeyUsageOid — Resolve an ExtendedKeyUsage to its dotted-decimal OID.
  • parseAuthorityInfoAccessMethodOid — Map a dotted-decimal OID to an AuthorityInfoAccessMethod value.
  • parseExtendedKeyUsageOid — Map a dotted-decimal OID to an ExtendedKeyUsage value.
  • encodeName — DER-encodes an X.509 Name.
  • encodeRelativeDistinguishedName — DER-encodes a single RelativeDistinguishedName (RDN).
  • decodeExtension — Decode a single extension using a custom ExtensionDecoder.
  • decodeExtensionMap — Decode all matching extensions using a named ExtensionDecoderMap.
  • decodeExtensions — Decode all matching extensions using an array of ExtensionDecoders.
  • defineExtensionDecoder — Identity helper that narrows the type of a custom ExtensionDecoder literal.
  • defineExtensionDecoderMap — Identity helper that narrows the type of a custom ExtensionDecoderMap literal.
  • findExtension — Find a raw extension by OID within a parsed extension list.
  • parseCertificateChainPem — Decode a PEM bundle containing one or more certificates.
  • parseCertificateDer — Decode a DER-encoded X.509 certificate into a ParsedCertificate.
  • parseCertificatePem — Decode a PEM-encoded X.509 certificate into a ParsedCertificate.
  • parseCertificateSigningRequestDer — Decode a DER-encoded PKCS#10 CSR into a ParsedCertificateSigningRequest.
  • parseCertificateSigningRequestPem — Decode a PEM-encoded PKCS#10 CSR into a ParsedCertificateSigningRequest.

  • UserNoticePolicyQualifierInfo — UserNotice policy qualifier — human-readable notice text and/or a notice reference.

  • ParsedExtension — A raw X.509v3 extension before type-specific decoding.
  • ParsedName — An X.501 Distinguished Name decoded from an issuer or subject field.
